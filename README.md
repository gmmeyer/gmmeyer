# Hi, I'm Greg Meyer 👋

I'm a software engineer in New York. I'm currently a founding engineer at [Zingage](https://zingage.com), building AI agents that run operations for home care agencies. Before that I co-founded Bearworks, and before that I helped scale the Datadog Agent through hypergrowth.

Outside of work I train small models from scratch, practice post-training, and put the fun ones in the browser.

## Recent projects

- **[grix](https://github.com/gmmeyer/grix)** ([site](https://grixos.dev)): a Rust unikernel sandbox for AI agents. It boots a fresh microVM for every run, implements the Linux syscall ABI itself, and checks every call against the capabilities you grant. It ships its own VMM on Hypervisor.framework and KVM, and a run takes about 0.1 s.
- **[NYC Heroes](https://github.com/gmmeyer/nycheroes)** ([play](https://nycheroes.party)): a browser superhero game set in a 1:1 New York, with all ~1.08M buildings from the city's open data and co-op multiplayer over WebRTC. I built it with Claude and Godot in about three days.
- **[Cicero](https://github.com/gmmeyer/cicero-llm)** ([try it](https://cicerollm.com)): a ~111M-parameter Latin language model trained from scratch. It runs entirely in your browser via ONNX Runtime Web.
- **[The Dreaming Bird](https://github.com/gmmeyer/gptbird)** ([play](https://gmmeyer.github.io/gpt-bird/)): an ~11M-parameter world model that *is* Flappy Bird. There's no physics engine; the model generates every frame.
- **[midigpt](https://github.com/gmmeyer/midigpt)**: a transformer that generates expressive solo piano, trained on MAESTRO.
- **[spritegpt](https://github.com/gmmeyer/sprite-diffusion)**: a pixel-space diffusion model for emoji and game sprites.
